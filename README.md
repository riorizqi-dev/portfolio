# Portfolio

Personal portfolio website built with React 19 + TypeScript + Vite + Tailwind CSS.

## Features

- Animated hero & section transitions (Framer Motion)
- Project showcase with cards
- Tech stack section
- Contact form (Supabase-backed)
- Fully responsive

## Stack

- React 19, TypeScript, Vite 6
- Tailwind CSS 4
- Framer Motion
- Supabase (contact form)

## Run Locally

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` to enable the contact form.
